This application was developed as the final project for a Master's module at Hallam University. The purpose of the application is to provide users with information about planets within the Solar System.

The application includes input validation to improve usability and reliability. User input is processed to handle differences in capitalisation and ignore common formatting mistakes, helping to ensure valid planet names are recognised correctly. Clear error messages are displayed when invalid input is entered.

The graphical user interface is split across multiple screens, enabling users to select a planet and then view different categories of information through dedicated buttons. Information available includes planetary mass, distance from the Sun, number of moons, and moon names. The interface provides immediate feedback and allows users to select a new planet without restarting the application.

This project demonstrates key programming concepts including object-oriented programming, functions, data structures, conditional statements, input validation, graphical user interface development, and event-driven programming. It also highlights the importance of user experience considerations, error handling, and code organisation when developing desktop applications.


Key skills demonstrated:

Python programming
Object-oriented programming (classes and objects)
Tkinter GUI development
Input validation
Data storage and retrieval
Event-driven programming
Function design and modular programming
Error handling and user feedback
Use of lists and custom data structures
User interface design


A testing plan was also produced to outline how the application's functionality could be verified. While formal automated testing was not implemented, manual testing was conducted throughout development to ensure that key features, including user input validation, navigation between screens, and data retrieval functions, operated as expected.

# Planet Information Application

## Overview

This application was developed as the final assessment for the Fundamentals of Computing module at Sheffield Hallam University.

The application allows users to retrieve information about planets within the Solar System through an interactive graphical user interface built with Python and Tkinter.

## Features

- Planet information lookup
- Object-oriented design using a custom Planet class
- GUI built with Tkinter
- Input validation
- Error handling and user feedback
- Display of mass, distance from the Sun, number of moons, and moon names

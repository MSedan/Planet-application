This application was developed as the final project for a Master's module at Hallam University. The purpose of the application is to provide users with information about planets within the Solar System.

The application was built using Python and features an interactive graphical user interface (GUI). Users can enter the name of a planet and receive immediate feedback indicating whether the entered object is a valid planet. If the input is valid, the application displays the relevant planetary information; otherwise, it informs the user that the entry is not recognised as a planet.
To improve usability and reduce input errors, validation checks were implemented to ignore leading and trailing spaces, as well as accidental capitalisation. This allows users to enter planet names in different formats while still receiving accurate results.
The application demonstrates the use of Python programming concepts, including functions, conditional statements, data structures, exception handling, and GUI development. It was designed with a focus on user experience, providing clear feedback and simple navigation. The project also highlights the importance of data validation and error handling when developing user-facing applications.
